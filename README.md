## Nasazení na GitHub Pages
1. Přihlas se na https://github.com/ a vytvoř nový veřejný repozitář, například `baulord-web`.
2. Nahraj `index.html` do kořenové složky repozitáře (`Add file` → `Upload files` → `Commit changes`).
3. Otevři `Settings` → `Pages`.
4. V části `Build and deployment` zvol `Deploy from a branch`.
5. Vyber větev `main` a složku `/(root)`, pak klikni `Save`.
6. Po dokončení nasazení se adresa webu zobrazí v části Pages, typicky `https://TVE-UZIVATELSKE-JMENO.github.io/baulord-web/`.
7. Zkontroluj stránku na mobilu i počítači a otestuj telefon, e-mail i WhatsApp.

GitHub Pages může po prvním nastavení potřebovat několik minut na zveřejnění. Repozitář bude veřejný, takže nevkládej žádná tajná data.
